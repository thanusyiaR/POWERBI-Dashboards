# Superstore Sales & Performance Dashboard | Power BI

## Project Overview

This project demonstrates the use of **Microsoft Power BI to analyze Superstore sales, profitability, customer, product, and regional performance**.

The dashboard transforms business data into interactive visualizations and KPIs to support performance monitoring and data-driven decision-making.

## Project Objectives

- Analyze overall sales and profit performance
- Monitor key business KPIs
- Compare regional and geographic performance
- Analyze product and category performance
- Identify profitable and underperforming areas
- Explore customer and sales trends
- Transform raw data into actionable business insights
