# Learner Analytics Dashboard | Power BI & KPI Reporting

## Project Overview

This project demonstrates the use of **Business Intelligence and data analytics to monitor learner performance and key performance indicators (KPIs)**.

The dashboard transforms learner data into meaningful insights that can support training teams, LMS administrators, managers, and organizations in monitoring learning progress and identifying areas for improvement.

## Project Objectives

- Monitor learner performance through KPIs
- Analyze training and learning outcomes
- Identify performance trends and patterns
- Compare learner results
- Support data-driven training decisions
- Present learner information through clear visual reporting
- Identify opportunities for learning and performance improvement
